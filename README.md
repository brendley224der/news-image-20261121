## How to run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

That writes `entry.png` (1024×1024, one day's news) into `out/`. The program uses only the Python standard library and produces byte-identical output on every run. `paper.py` holds the drawing kit (a hand-made 5x7 bitmap font, shape primitives and a deterministic PNG writer); `main.py` lays out the front page.
